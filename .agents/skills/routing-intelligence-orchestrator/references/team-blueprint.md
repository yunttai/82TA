# Routing Team Reconfiguration Blueprint

## Team A — Provider and Mapping
lead, provider, mapping, data, QA, optional security

## Team B — Intelligence and Optimization
lead, optimizer, bus intelligence, data/ML, mapping/provider dependency, QA

## Team C — API and Release
lead, security/performance, QA, contract steward, integration QA

Before subagent completion and cleanup, every team writes:
- completed tasks
- canonical inputs/outputs
- versions and hashes
- unresolved blockers
- tests and replay IDs
- next-team handoff
