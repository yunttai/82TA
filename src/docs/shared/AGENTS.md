# Shared Product Documentation Scope

- Joint stewardship. Product semantics, PRD, context map, ERD, NFR, security and release gates describe accepted requirements or targets for their stated scope.
- When documentation and the current implementation differ, report the gap and follow the user's requested scope; do not rewrite implementation solely to satisfy roadmap or historical wording.
- Harness-only migrations may update only harness/source-layout references, not product meaning.
